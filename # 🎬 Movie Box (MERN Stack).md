# 🎬 Movie Box (MERN Stack)

A modern, full-stack movie discovery and rating web application built with MongoDB, Express, React (Vite), and Node.js.

## ✨ Features
- **Comprehensive Movie Explorer:** Filter by genre, release year, language, and minimum ratings using MongoDB's `sample_mflix` dataset.
- **Dynamic "Suggest Movie":** Random recommendation engine powered by MongoDB aggregation pipelines.
- **Interactive Ratings:** User rating system with real-time score updates.
- **Responsive Interface:** Fast client rendering built with React and Vite.

## 🛠️ Tech Stack
- **Database:** MongoDB Atlas (Cloud)
- **Backend:** Node.js, Express.js, Mongoose
- **Frontend:** React, Vite, Axios, CSS Modules / Tailwind CSS
- **Deployment:** Render (API) & Vercel (Client)
